# PRIVÉE — The Marafie Collection

[![CI](https://github.com/mish5000/maison-x9k2m7q4/actions/workflows/ci.yml/badge.svg)](https://github.com/mish5000/maison-x9k2m7q4/actions/workflows/ci.yml)

A private, offline-capable travel and dining guide, shipped as an installable
progressive web app. It covers 22 cities, 213 curated restaurants and 14
nightclubs, with per-venue signature dishes and nightly DJ line-ups.

This repository is the **deployed artifact**, not the source. It is the static
site GitHub Pages serves and the PWA that installs from it. The application
source, the curation pipeline and the scrapers that produce the data files live
in the `apps/privee`, `curation/` and `scripts/lineups/` trees of the
[`anthropic-daily`](https://github.com/mish5000/anthropic-daily) repository, on
the `claude/luxury-entertainment-app-h4chlk` branch.

> **Read this before pushing:** every commit to `main` publishes to the live
> site and reaches installed devices on their next launch. See
> [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md).

---

## Contents

| Path | What it is |
| --- | --- |
| `index.html` | The entire application — markup, styles and logic in one self-contained file (~1.5 MB) |
| `sw.js` | Service worker. Caches the shell for offline use; never allowed to block a load |
| `manifest.json` | PWA manifest — name, colours, icons, standalone display |
| `version.json` | Build stamp (`v`) and human build date. The app polls this to detect updates |
| `dishes.json` | 213 venues across 22 cities, each with signature dishes and sourcing |
| `lineups.json` | 14 nightclubs with dated DJ line-ups, party, doors and confidence |
| `assets/` | 1,997 venue photographs, ~113 MB, served locally so the app works offline |
| `icon-180.png`, `icon-512.png` | Home-screen and manifest icons |

There is no build step in this repository. What is committed is what is served.

## Running it locally

The app fetches `dishes.json`, `lineups.json` and `version.json` over HTTP and
registers a service worker, so opening `index.html` from the filesystem will not
work. Serve the directory instead:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>. Any static file server works.

To exercise the offline path, load the page once online, then go offline and
reload — the service worker serves the cached shell.

## Data shape

Both data files are keyed `city|category|index`, so `london|restaurants|0` is the
first London restaurant.

`dishes.json` — categories `restaurants` and `whatsnew`:

```json
{
  "generated": "2026-08-01T19:10:58Z",
  "venues": {
    "london|restaurants|0": {
      "dishes": [
        {
          "n": "Ravioli — lobster, langoustine, salmon",
          "why": "On the menu since 1998 and still the plate regulars order first.",
          "src": ["michelin", "infatuation", "google"],
          "n_src": 3
        }
      ]
    }
  }
}
```

`lineups.json` — category `nightclubs`, keyed by date under `nights`:

```json
{
  "generated": "2026-08-05T03:12:27Z",
  "venues": {
    "ibiza|nightclubs|0": {
      "nights": {
        "2026-08-04": {
          "hl": "East End Dubs",
          "line": ["East End Dubs B2B Franky Rizardo", "Obskür"],
          "party": "Eastenderz",
          "doors": "23:30",
          "src": "ibiza-spotlight.com",
          "conf": "high"
        }
      }
    }
  }
}
```

`n_src` is the number of independent sources that agreed on a dish; `conf` is the
scraper's confidence in a line-up. Both exist so the interface can distinguish
corroborated entries from single-source ones. Do not hand-edit either file —
they are regenerated by the pipeline and your edits will be overwritten.

CI validates the structure of both files on every push. See
[`.github/workflows/ci.yml`](.github/workflows/ci.yml).
